# 封面圖規格與生圖 prompt

- 檔名：`assets/covers/<id>.jpg`（id 見下表），放進來就會自動顯示，缺檔會退回直排書名的佔位封面。
- 尺寸：直式 3:4，建議 900x1200，JPG 品質 80 左右，每張控制在 200KB 以內。
- 圖上**不要有任何文字**，書名跟作者由網頁壓在封面下方。
- 版權紅線：只用原創插畫，不可複製官方封面或角色設定；prompt 都以物件、場景、剪影描述。
