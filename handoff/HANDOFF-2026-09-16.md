### 2.1 本輪教訓

1. **測試全綠 ≠ 畫面能看。** P-ui 測試全過，但真 Chrome 裡淺色書卡白底白字。
   用全部 76 本的真實 `color` 算 WCAG 對比：**50 本 < 3.0**。已寫成 `check_card_contrast.mjs`（讀 CSS 混色比例計算），以後改配色不會退步。
2. **headless 截圖會拍在 CSS 進場動畫中途**，兩次讓我誤判「書架只剩 3 本」。反過來，真 Chrome 擴充截圖的顏色會失真偏淡——
   **顏色以 `getComputedStyle` 讀值為準、互動以頁內 JS 觸發後讀 DOM 為準**，不要只看圖。
3. **我寫的契約測試有一個 bug**：`test_data_status.py` 原本以 `HEAD` 當比對基準，資料 commit 進去後基準跟著移動、整批誤報。已改為固定 `84c342e`。
4. **opencode 存截圖到 `/tmp` 會跳「存取外部資料夾」權限提示**，builder 就卡在 blocked。之後工作包一律指定存 `.git/wp/shots/`。
5. **免費席次在「紅測試契約＋明確可動檔案清單」下表現穩定**：三席平行零互撞、零改測試、零假資料 fallback；
   P-page2 遇到自己無權改的 `style.css` 缺口時照實回報，沒有越界。

### 4.1 `/security-review` 結論

**無高／中風險發現**（2026-09-16，範圍 `origin/master..133cce4`，由 Sonnet 子代理逐一追蹤資料流，Observation 層、未另行複核）。
追過的入口與出口：`?q=`／`?id=`／`?ch=`／`?src=`、`#libSearch`、`#siteSearch` → `cardHTML()`（所有欄位與 href、`--c` 顏色皆經 `esc()`）、
`renderLibrary()`（查詢字串進 innerHTML 時有 `esc()`，進計數用 `textContent`）、`syncURL()`（固定路徑＋`encodeURIComponent`）、
類型／狀態按鈕（`data-g` 經 `esc()`、`data-s` 為固定值）、`bookHref()`（`encodeURIComponent(id)`＋白名單 src）。
查詢字串跳脫另有契約測試守著（`check_library_page.mjs` 以 `?q=<img src=x onerror=alert(1)>` 在 node:vm 驗證，**不是真瀏覽器實測**）；

備註（範圍外、不列發現）：`copyBook()` 逐鍵複製若資料檔含 `__proto__` 鍵會改到區域物件原型，但資料檔由 repo 控制，非攻擊者可達。
